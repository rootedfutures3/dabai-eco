The Platform

一個平台，兩端解決

果農的果子爛在樹上，收購商卻找不到穩定貨源 —— 問題從來不是產量，是連不起來。 我們做的是一套把兩邊接起來的系統：果農上架果園與樹況資訊，收購商依據資料認養果樹或整片果園， 平台再派農務顧問下田，確保這批貨真的長得出來。

The Problem

產量過剩，不等於有人買

砂拉越的 Dabai 與榴槤產季集中、保存期短。同一時間所有果子一起熟， 價格被壓到谷底，賣不掉的直接爛在地上。而另一頭，加工廠與出口商為了搶不到穩定貨源而停線。

Supply · 供給端

果農的困境

  • 產季一到全部同時成熟，中盤商壓價收購
  • 沒有通路，只能等人上門，賣不掉就爛掉
  • 不知道自己的樹值多少錢，議價毫無依據
  • 不懂施肥與病蟲害管理，收成一年比一年差
  • 需要現金週轉，卻要等到收成後才拿得到錢

How It Works

像叫車一樣媒合，
但媒合的是果樹

叫車平台一邊是司機、一邊是乘客，平台負責媒合與信任。 我們一邊是果農、一邊是收購商，平台負責媒合、資訊透明與農務品質把關。

🌱 果農這一端

1
登記果園提供地點、作物、樹齡、樹數與歷年產量，平台協助建檔。
2
顧問實地勘查農務顧問到場檢視樹況、土壤與病蟲害，給出健康評級。
3
果園上架經查核的資料公開在平台上，收購商可直接檢視與比較。
4
收成前拿到訂金認養成立後即撥付部分款項，解決產季前的現金壓力。

🏭 收購商這一端

1
瀏覽與篩選依作物、地區、樹齡、預估產量與健康評級找到合適的果園。
2
認養果樹或果園單棵認養、整片認養或契作包銷，依採購規模自由選擇。
3
全程追蹤樹況顧問定期回報開花、結果與預估產量，出貨前不再是黑箱。
4
產季直送履歷完整收成後直送，附帶產地、樹齡與農務紀錄，可用於出口與 ESG 稽核。
為什麼是「認養」而不是「下訂單」？ 下訂單是產季到了才議價，果農依然承擔全部風險。認養是提前綁定 —— 收購商在開花前就確定了這批果子的歸屬，果農提前拿到現金、確定有人收； 收購商鎖住貨源、還能透過顧問影響最終品質。風險從單邊變成共擔。
Adoption Models

三種認養規模

從小量試單到整季包銷，依採購需求選擇綁定深度。

單棵認養

Per Tree · 入門
  • 認養指定的單棵或數棵果樹
  • 收成全數歸認養方
  • 顧問提供基礎樹況回報
  • 附掛牌與產地履歷
適合：小型加工坊、餐飲業者、企業 ESG 認養宣傳、想試水溫的新客戶。
最多人選擇

整片果園認養

Per Orchard · 主力
  • 認養整片果園的當季產出
  • 顧問全季駐點管理與定期回報
  • 可指定採收規格與分級標準
  • 優先續約權，鎖定長期貨源
  • 完整產銷履歷，可用於出口稽核
適合：食品加工廠、冷鏈出口商、需要穩定量與規格一致的中大型買家。

契作包銷

Contract Farming · 深度
  • 多年期契約，鎖定價格與產量
  • 平台協助導入標準化農法
  • 共同投資樹苗與灌溉設施
  • 產量成長後的收益分潤機制
適合：品牌商、大型通路、有長期供應鏈與碳足跡揭露需求的企業。

Advisory

農務顧問 —— 平台的品質保證

很多果農其實不知道怎麼照顧 Dabai 和榴槤樹 —— 樹是祖先種的，收成好壞看天。 光是把兩邊接起來還不夠，貨的品質要撐得住，媒合才有意義。顧問是這套系統的核心，不是附加服務。

🔍

樹況診斷與評級

實地檢視樹齡、樹勢、病蟲害與土壤狀況，給出 A／B／C 健康評級，作為收購商認養的判斷依據。

🧪

施肥與土壤指導

依土壤檢測結果制定施肥計畫，教果農什麼時候施、施多少、施什麼，而不是憑經驗亂灑。

📊

果實品質分析

檢測果實大小、油脂含量、成熟度與分級標準，讓同一批貨的規格一致，收購商才敢下大單。

📈

產量預測

從開花期就開始追蹤，提前估算產季產量，讓收購商能安排產線、果農能安排人力。

🎓

果農培訓

定期在長屋開課，把修枝、疏果、採後處理的技術留在社區，而不是每次都要顧問親自來。

📋

產銷履歷建檔

每次農務作業都記錄在案，形成可追溯的履歷 —— 這是出口與企業 ESG 稽核的必要文件。

The Tree ID System

一棵樹，怎麼變成
一筆可以買賣的資產

這是整個平台的核心。Tree ID 把一棵原本只能等中盤商上門的樹， 變成有身分、有紀錄、可以在開花前就先賣掉的資產。

  1. 1

    掛牌

    農務顧問到果園實地勘查，記錄樹齡、樹勢、土壤與預估產量，在樹幹掛上實體標牌。

  2. 2

    取得 Tree ID

    每棵樹拿到唯一編號（例如 DB-001），從此它的每一次施肥、每一張照片、每一筆交易都掛在這個編號底下。

  3. 3

    上架平台

    果農是誰、果園在哪、樹齡幾年、健康評級 A／B／C —— 買方在螢幕上看得到，不必先飛一趟砂拉越。

  4. 4

    開花前認養

    買方在果實還沒長出來以前就付款買下整棵樹的收成。錢當場拆帳：果農 80%、平台 20%，果農不必再等收成才有現金。

  5. 5

    產季照護與回報

    溝通者定期到現場拍照回報，顧問追蹤花況與預估產量。全部寫進這棵樹的紀錄，形成可稽核的產銷履歷。

  6. 6

    採收與履約

    果園 → 舢舨 → Song 碼頭 → 貨車 → 買方。平台不建倉庫、不壓貨、不養車隊，果子從樹上直接走到買方手上。

差別在哪？ 一般的農產電商是「果子採下來以後，幫你找買家」—— 果農仍然承擔賣不掉的風險，而 Dabai 只有三天可以賣。 Tree ID 把交易提前到開花之前：風險變成共擔，果農先拿到錢， 買方鎖住貨源，中間沒有人再靠壓價賺差價。
Revenue Model

平台怎麼賺錢

三條收入線。主力是認養佣金 —— 向買方收，不從果農身上剝皮。

①

認養佣金 主力

認養成立時抽 20%，其餘 80% 全數給果農，其中大部分在開花前就先撥。這條線取代了原本層層中盤的抽成。

②

直銷佣金

沒被認養的樹，由平台代為收購並按公斤賣給餐廳、飯店與加工廠，再向果農收一筆佣金 —— 讓剩下的果子也有去處。

③

果樹保險

天災或歉收時保障認養人的權益。附加服務，細節仍在規劃中。

輕資產是刻意的。 平台不建冷藏庫、不壓貨、不養車隊，也不做存貨融資 —— 所以每多接一棵樹，幾乎不增加固定成本。 這個模式的槓桿在樹的數量與認養率，而不是在資本支出。
